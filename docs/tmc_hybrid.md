# Настройка эталонного HYBRID-расчёта TMC

Отдельный макрос и полная инструкция находятся в [tmc/README.md](../tmc/README.md).

Он рассчитан на загруженные пользователем эталоны двух подканалов: SRH/SST, постоянные свойства, периодическая длина 300 мм, шаг 11,64 мм, твэл 9,1 мм. Макрос настраивает нагрев/сток и периодичность, создаёт геометрию отчётов по существующим Derived Parts, мгновенные отчёты и необходимые мониторы, а также управляет фазами разгона и временными блоками статистики.

Средние скалярных отчётов взвешиваются по фактическому времени. TMC определяется отношением согласованных средних с поправкой на накопление чувствительной энергии. Средние поля — отдельная опция с постоянным шагом и проверкой API паузы.

STAR-CCM+ и Siemens SDK в среде разработки отсутствуют. Компиляция на тестовых контрактах проверяет синтаксис и внутреннюю Java-логику, а не совместимость с фактическим SDK. Первый запуск выполняется на копии `.sim`; применимость физической постановки, дискретизации, статистическое установление, знаки и реальные вызовы 2602 требуют проверки пользователем.

## Экспорт из GUI

В окне экспорта STAR-CCM+ выберите режим **HYBRID / TMC — эталон двух подканалов, 300 мм**.
Обычный экспорт остаётся отдельным режимом. В TMC доступны четыре вкладки:
комплект и совместимость сетки; постоянные свойства и нагрев; шаг времени и длительности этапов;
состав отчётов и необязательные средние поля. Настройки сохраняются в профиле экспорта и проекте.

Этот режим поддерживает только эталон S18/S22 с шагом 11,64 мм, диаметром 9,1 мм,
длиной 300 мм и конформной полной сеткой. Другую геометрию нужно экспортировать обычным способом;
адаптация TMC к ней требует отдельной проверки геометрии, знаков и периодических пар.

Выберите папку комплекта: программа создаст XYZ, `setup_starccm_subchannels.java`,
`TMC_Hybrid.java`, `TMC_export.json`, `TMC_START.txt`, `TMC_analyse_series.py`.
Файлы сначала готовятся во временных файлах; отмена до публикации сохраняет прежний комплект.
При ошибке публикации выполняется откат. Если сам откат не удаётся, сообщение указывает сохранённую
резервную копию. Во время короткой публикации отмена не обрабатывается.

Порядок для нового расчёта: импортный макрос → TMC Action=0 → проверка условий → Initialize в STAR.
После этого этапами управляет параметр `TMC_Action`; экспорт и Action=0 сами расчёт не запускают.
Полевые средние отключены по умолчанию: их совместимость с API STAR-CCM+ 2602 нужно проверить
на копии симуляции. Проверка Java по тестовым контрактам не заменяет компиляцию с Siemens SDK.

Значения формы используются при первом создании параметров `TMC_`. Повторный запуск сохраняет
существующие параметры в симуляции; меняйте их в STAR, чтобы не сбросить этапы и статистику.

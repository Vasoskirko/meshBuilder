# Настройка эталонного HYBRID-расчёта TMC

Отдельный макрос и полная инструкция находятся в [tmc/README.md](../tmc/README.md).

Он рассчитан на загруженные пользователем эталоны двух подканалов: SRH/SST, постоянные свойства, периодическая длина 300 мм, шаг 11,64 мм, твэл 9,1 мм. Макрос настраивает нагрев/сток и периодичность, создаёт геометрию отчётов по существующим Derived Parts, мгновенные отчёты и необходимые мониторы, а также управляет фазами разгона и временными блоками статистики.

Средние скалярных отчётов взвешиваются по фактическому времени. TMC определяется отношением согласованных средних с поправкой на накопление чувствительной энергии. Средние поля — отдельная опция с постоянным шагом и проверкой API паузы.

STAR-CCM+ и Siemens SDK в среде разработки отсутствуют. Компиляция на тестовых контрактах проверяет синтаксис и внутреннюю Java-логику, а не совместимость с фактическим SDK. Первый запуск выполняется на копии `.sim`; применимость физической постановки, дискретизации, статистическое установление, знаки и реальные вызовы 2602 требуют проверки пользователем.

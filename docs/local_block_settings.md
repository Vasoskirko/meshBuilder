# Локальные настройки блоков

Область «Ко всем блокам» задаёт параметры по умолчанию. «По шаблону» задаёт переопределение для блоков этого шаблона. «Для блока» позволяет изменить один или несколько блоков. Собственные настройки блока имеют приоритет перед шаблоном и общими параметрами. Z и nz всегда общие; ni, распределение по нормали и параметры слоя/ядра можно менять локально.

## Выбор и редактирование

В дереве выделите несколько блоков с Ctrl или диапазон с Shift. На рисунке можно выбрать блок нажатием, добавлять/снимать выделение с Ctrl. Выбор на рисунке не выполняется во время линейки, панорамирования/масштабирования и просмотра диагностики ячеек. Выделенные блоки обозначены синей меткой Б№. Звёздочка ★ означает индивидуальные настройки; она не указывает на ошибку стыка. Контуры блоков нейтральные, включая границы стержней.

Редактор показывает параметры первого выбранного блока. Для различающихся числовых параметров отображается «Разные значения», текстовая подсказка перечисляет различия, в том числе режимы распределения. Изменение поля применяется ко всем выделенным блокам; остальные параметры каждого сохраняются. Построение собирает всю выбранную геометрию, а не только выделенные блоки. Переключение области/выделения без редактирования не должно сбрасывать сетку.

Параметры ядра наследуются отдельно: собственное ядро блока → ядро шаблона → общее ядро. Изменение только ядра сохраняет пригодный слой. Изменение ni, нормали или слоя требует перестроения. Ядро заполняется по группам с одинаковыми эффективными настройками и ni; разные группы могут иметь разное число слоёв. Блоки с обычным полным распределением можно сочетать с блоками независимого слоя; при заполнении уже полные блоки сохраняются.

Кнопка сброса для блока сбрасывает переопределения всех выделенных блоков. Для шаблона — выбранного шаблона. В общей области — все переопределения, сохраняя общие параметры. Настройки ядра/стенки сбрасываются вместе; отдельного сброса только ядра пока нет.

## Диагностика стыков

Построение проверяет положительность ячеек. Вместо отказа при несовпадении узлов оно предлагает принять результат для просмотра. При отказе новый результат не принимается, устаревшая сетка не становится доступной для экспорта.

- Красная сплошная линия с белой подложкой: геометрические полилинии совпадают в пределах допуска, но число или положения узлов отличаются — неконформный стык.
- Пурпурный пунктир с белой подложкой: полилинии не совпадают. Возможны щель, наложение либо разные фронты незаполненных слоёв; это не объявляется корректным интерфейсом. После заполнения стыки проверяются заново.

Стыки пронумерованы С1, С2 и т.д., номера соответствуют порядку в отчёте качества. На рисунке подписаны первые 20 проблемных стыков, линии показаны для всех; значения цветов объясняет легенда. Журнал и отчёт качества отмечают проблемы. Метрики конформных интерфейсов не включают такие стыки. Подтверждение предупреждения не исправляет геометрию и не является заключением о пригодности для расчёта. Это диагностика предполагаемых стыков построенной топологии, не универсальный поиск всех пересечений произвольных блоков.

## Экспорт

Полную сетку с совпадающей геометрией, но разным разбиением можно сохранить в многоблочный Plot3D для диагностики. Сам формат координат не описывает сопряжение и не гарантирует импорт как связной CFD-области. При несовпадении геометрии экспорт Plot3D блокируется непосредственно в обработчике записи, до изменения файла.

**Текущий STAR-CCM+ экспорт, включая Fuse, требует конформных стыков внутри блоковой сборки.** Сетки с диагностированными проблемами доступны для просмотра, но этот экспорт блокируется в GUI и обработчиках. STAR-CCM+ поддерживает неконформные интерфейсы при правильном разделении областей/границ; создание отдельных регионов для локальных блоков и таких интерфейсов пока не реализовано. Простое подтверждение предупреждения не включает эту возможность.

Полный проект сохраняет локальные настройки в формате версии 2. Версия 1 читается; старые версии программы могут не открыть новый проект. Множественное выделение временное: после открытия восстанавливается один активный блок, сами настройки всех блоков остаются.

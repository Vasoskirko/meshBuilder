# Полный проект конструктора подканалов

Используйте меню **Проект → Сохранить проект** (`Ctrl+S`), **Сохранить проект как…** (`Ctrl+Shift+S`) и **Открыть проект…** (`Ctrl+O`). Меню доступно на всех вкладках; на вкладке геометрии есть также кнопки сохранения и открытия. Первое сохранение предлагает имя `bundle_project.json`; последующие Ctrl+S обновляют выбранный файл.

## Что сохраняется

- Применённая геометрия пучка, все ручные типы/диаметры стержней (включая стержни вне выбранных подканалов), ручные удаления и удаления при подтверждении коллизий.
- Выбранные подканалы и их идентичность по координатам стержней, а не только номеру.
- Общие сеточные параметры, переопределения шаблонов/блоков и их геометрические привязки.
- Общие и локальные настройки ядра для шаблонов/блоков: способ заполнения ядра, переход r, рост q, размер/лимит/число слоёв, форма линий, метод центра и единицы отображения.
- Введённые настройки калькулятора y+, включая выбранный газ и модель теплопроводности. Производные свойства и вязкий масштаб пересчитываются после загрузки из этих входов; некорректный черновик не восстанавливает старые числовые результаты.
- Последние корректные настройки окна STAR-CCM+, включая Δt, группы полей/отчётов, физику и выбранные сечения. Настройки запоминаются при закрытии окна экспорта. После построения сетки они применяются при следующем открытии окна. Если они не подходят изменившемуся составу сетки, журнал сообщает об этом, окно открывается с настройками по умолчанию.
- Активная вкладка, детализация рисунка и область редактирования/выбранный шаблон или блок.

Поля геометрии, изменённые без нажатия «Сбросить и перестроить пучок стержней», сохраняются отдельно от применённой модели. После открытия они остаются в полях; журнал напоминает, что для применения нужно перестроить пучок. Кнопка перестроения, как и прежде, сбрасывает ручные правки стержней. Проект не применяет такое разрушительное действие автоматически.

Неподтверждённый корректный текст Z/nz и активных сеточных полей считывается перед сохранением. Некорректные сеточные числа нужно исправить: приложение сообщит об ошибке, существующий файл проекта не будет перезаписан. Калькулятор допускает сохранение своих текстовых черновиков, но не использует их как рассчитанные физические величины.

## После открытия

Сетка, пристеночный слой и результаты проверки качества **не загружаются**. Они зависят от актуальных алгоритмов и восстанавливаются повторным построением. Экспорт и заполнение отсутствующего слоя заблокированы до выполнения соответствующих этапов. Сохранение неизменённых настроек уже построенной сетки само по себе её не инвалидирует.

Вариант A для сравнения и подсветка ячеек также не сохраняются; открытие проекта очищает их. История журнала, положение окна, панорамирование и временные измерения линейкой не являются параметрами проекта и не сохраняются. Результаты CFD в этот формат не входят.

## Старые файлы и совместимость

Открытие распознаёт прежний JSON сечения `bundle-cross-section`, версия 3. Геометрия и выбор восстанавливаются; отсутствующие в старом файле сеточные параметры, настройки калькулятора/экспорта получают значения по умолчанию. Правки невыбранных стержней, которых старый файл не содержал, восстановить из него невозможно. При последующем сохранении предлагается новый файл полного проекта, чтобы не подменить старый формат без выбора пути.

Для прежнего геометрического JSON используйте **Проект → Экспортировать только сечение JSON…**. Полный проект конструктора и проект отдельного GUI `mesh_gui.py` — разные форматы; они не подменяют друг друга.

Текущий формат: `meshBuilder-bundle-project`, версия 2, UTF-8 JSON (проекты версии 1 читаются с добавлением локальных настроек ядра по умолчанию). Геометрия пучка хранится в миллиметрах, параметры сетки/ядра — в SI, отображаемые единицы задаются отдельно. Неизвестная версия, повторяющиеся поля JSON, неконечные числовые значения, недоступные подканалы или несовпадающие привязки переопределений отклоняются до изменения текущего проекта. При изменении алгоритма геометрии/SciPy привязки могут перестать совпадать: приложение откажет в загрузке вместо применения настроек к другим блокам.

Запись использует временный файл в каталоге назначения и атомарную замену готового файла. Размер читаемого JSON ограничен 16 МиБ. Открытие/сохранение во время фонового построения или экспорта запрещено до завершения/отмены операции.

Числовые поля геометрии пучка, диаметра выбранного стержня и порога диагностики принимают точку и запятую как десятичный разделитель независимо от локали. Отображение остаётся локализованным; диапазоны, точность и шаг стрелок сохранены. Разделители разрядов для этих полей не используются.

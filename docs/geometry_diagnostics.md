# Геометрия сечения: диагностика и структура

## Что проверяется

Проверка относится ко **всей построенной геометрии**, независимо от выбранных
подканалов. Она ищет непокрытую жидкость, перекрытия подканалов, некорректные
полигоны, пересечения стержней друг с другом/оболочкой и несоответствие площади
гидравлики реальной жидкостной области. Никакая найденная дыра не заполняется
автоматически; положительный статус не означает пригодности CFD-ячеек.

Обозначим H — шестигранник, R — объединение круглых стержней, S_i — полигоны
подканалов. Непокрытая область: `(H \ union(S_i)) \ R`. Перекрытая область:
`union(S_i intersect S_j, i<j) intersect H \ R`. Область тройного перекрытия
считается один раз. Это независимые геометрические операции: дыра и перекрытие
не могут компенсировать друг друга, как при сравнении суммы площадей.

Shapely использует вписанные и описанные 128-угольники окружностей (32 сегмента
на четверть). Получаются нижняя и верхняя оценки площадей. Если нижняя оценка
дефекта больше численного допуска — дефект определён; если только верхняя —
нужна дополнительная проверка. Численный допуск равен max(площадь H × 1e-10,
1e-10) мм². Недопустимые полигоны исключаются из булевых операций и явно
отмечаются: результат с ними нельзя считать подтверждением полноты.

Например, при удалённом центральном стержне исходной сборки диагностируется
292.25…292.32 мм² непокрытой жидкости. Прямоугольный регрессионный пример с
суммой площадей ровно 100 мм², равной оболочке, независимо выявляет 20 мм² дыр
и 20 мм² перекрытий. Стержень внутри полигона, не учтённый гидравлическими
секторами этого подканала, выявляется сравнением площади с двумя оценками.

## GUI и скорость

На первом экране есть статус, «Проверка геометрии и подробности» и подсветка.
Красный контур показывает возможную непокрытую жидкость, оранжевый — перекрытие;
выводится до 20 внешних контуров каждого вида, а площади относятся ко всем
областям. Подробности содержат номера проблемных подканалов и стержней.

До 300 подканалов проверка выполняется автоматически и кэшируется; изменение
выборки не повторяет вычисления. Для больших моделей проверка запускается явно
в фоне с прогрессом и отменой между этапами. При изменении параметров за время
задачи устаревший результат отбрасывается существующим механизмом фоновых задач.
На 3571 стержне / 7140 подканалах прямая диагностика заняла около 6.6 с в среде
разработки; это не замер отрисовки и не гарантия на другом ПК.

Без Shapely приложение показывает «проверка недоступна», а не положительный
результат. Установка/обновление зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

При неподтверждённой полноте сводка GUI и таблица называют сумму гидравликой
**построенных подканалов**, а не всей жидкости сборки. Старый API
`get_total_assembly_summary()` сохранён: он суммирует построенные подканалы.
Для интерпретации этой суммы как всей сборки нужно учитывать диагностику.

Клик выбирает жидкостный полигон под указателем, исключая круги всех стержней.
Поиск по радиусу соседней метки больше не используется. На общей границе нужно
кликнуть внутри области; в перекрытии нескольких полигонов выбор не меняется и
показывается сообщение. Переход со стержня на подканал переключает инспектор.
Метки по возможности размещаются внутри гарантированной жидкостной области,
не меняя расчётный центр блока сетки.

## Точность и совместимость

Площади, периметры и Dh хранятся без округления, включая JSON. GUI форматирует
числа для чтения; CSV таблицы берёт исходные значения модели. Для стандартной
сборки полная площадь 2423.219714681342 мм², периметр 768.3479747896292 мм,
Dh 12.615220156439198 мм. После обновления следует пересчитать зависимые
гидравлические параметры/y+; сохранённые результаты CFD не исправляются.

## Файлы

```
meshbuilder/geometry/
  model.py         # публичный фасад BundleModel
  types.py         # RodData, Subchannel
  lattice.py       # координаты и перестроение модели
  subchannels.py   # генерация подканалов и соседства
  collisions.py    # пересечения стержней
  edits.py         # изменение, удаление и восстановление стержней
  hydraulics.py    # площади, периметры, Dh и суммы
  selection.py     # состояние выборки
  hit_test.py      # выбор области под указателем
  diagnostics.py  # независимая геометрическая диагностика
  validation.py   # проверки параметров и ограничение работы
  export.py       # JSON-представление сечения
  ui.py           # представление диагностики в Qt
```

`bundle_geometry.py` и `bundle_geometry_validation.py` — совместимые импорты.
Старые и новые пути предоставляют те же классы/функции; точки запуска сохранены.
Тесты покрывают прежние сценарии редактирования, аналитические суммы, точность,
отмену/фоновую задачу, выборку и совместимость импорта. Это регрессионная проверка,
не доказательство отсутствия любых геометрических ошибок. Автоматическое
восстановление дыр, Undo/Redo, ускорение самой отрисовки и CFD-экспорт угловых
областей в это изменение не входят.

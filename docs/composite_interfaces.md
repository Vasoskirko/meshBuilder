# Составные стыки блоков

`mesh_composite_interfaces.py` задаёт `CompositeInterface`: полная грань блока A
и две или более части `InterfacePiece`. Каждая часть ссылается на полную грань B,
диапазон индексов узлов A `[start_a, stop_a]` включительно и признак обратного
порядка узлов B. Соседние диапазоны имеют один общий узел, но не общие рёбра.

Пример для 37 узлов: часть слоя покрывает узлы 0…4, часть ядра — 4…36.
Проверка требует покрытия всей грани от 0 до 36 без дыр/перекрытий, не допускает
самосопряжение, повторное использование грани и нечисловые/повторяющиеся соседние
узлы. Неориентированный/неупорядоченный список частей сортируется по диапазонам.
Сопоставление всех узлов обязательно: одних совпавших концов недостаточно.

`partition_composite_interfaces` возвращает подтверждённые стыки и проблемы:
`nonconformal` — совпадает линия, но не узлы; `geometry_mismatch` — линии различны.
Неверная декларация покрытия вызывает ValueError. Параметр `pairwise` резервирует
грани обычных стыков: составной стык не может повторно использовать их.
`match_composite_interface` находит диапазоны и ориентацию по явному списку
кандидатов, затем выполняет полную проверку. Несовпавший кандидат не пропускается.

В `SubchannelMeshResult` добавлено поле `composite_interfaces` с пустым значением
по умолчанию. Это отдельные данные, не подмена существующего `BlockInterface`.
STAR-CCM+ экспорт результата с таким полем пока отклоняется: экспортеру требуется
разделение граней и правильное снятие меток границ на поддиапазонах. Заполнение
неполной сетки с составными стыками также отклоняется, чтобы не потерять данные.
Готовый результат возвращается заполнителем без изменений. Plot3D остаётся
форматом отдельных координатных блоков, без декларации этой связности.

Регрессии проверяют неверное покрытие, ориентацию, геометрические/узловые ошибки,
повторное владение гранью и защиту неподдерживаемых операций. Интеграционный тест
строит реальный внутренний подканал и периферийный прототип со слоем, связывает
обе половины межстержневого зазора на всех шести сторонах оболочки.

Это поддержка представления и проверки составных стыков. Автоматический поиск
соседей во всей сборке, GUI и экспорт периферийного CFD пока не подключены.

# Аудит геометрии сечения и выборки

Проверка модели BundleModel и обработчиков первого экрана конструктора.
Тесты: `tests/test_geometry_selection_audit.py`, `tests/test_geometry_gui_audit.py`.
Qt запускается с `QT_QPA_PLATFORM=offscreen`; диалоги подтверждения подменены управляемыми ответами.

## Найденные и исправленные ошибки

| Сценарий | Ошибка | Исправление |
| --- | --- | --- |
| Удаление стержня при выбранных подканалах | Устаревшие номера, KeyError, случайная привязка к новому подканалу с тем же номером | Выбор и активный подканал восстанавливаются по координатам стержней и положению относительно стенок |
| Индивидуальный диаметр обычного ТВЭЛа | Значение игнорировалось | Сохраняется переопределение; возврат к базовому диаметру/None снимает его |
| Ошибочное перестроение | Предыдущая геометрия и ручные настройки уничтожались до проверки | GUI строит проверенную копию, затем заменяет модель; модель проверяет ввод до очистки данных |
| Ноль, отрицательные числа, NaN/Infinity, неизвестные типы | Исключения деления/округления или некорректная геометрия | Явные ValueError до изменения модели |
| Огромное отношение размера оболочки к шагу | Неограниченный перебор координат, зависание | Ограничение до 20000 кандидатов решётки, совместимое с существующими диапазонами GUI |
| Остались три коллинеарных стержня | Исключение Qhull | Проверка ранга точек перед Delaunay |
| Угловые гидравлические области | Угол сектора 30° вместо фактического, неверные углы при разных диаметрах | Углы вычисляются по полигону каждого подканала |
| Только два стержня вдоль грани оболочки | Пропущена часть области у второго угла | Полигон включает оба конца грани; соседство учитывает оба угла |
| Пересекающиеся НК/ИК | Проверялись только пересечения с ТВЭЛами | Обе специальные трубы помечаются, не используются в жидкостных треугольниках |
| Диаметр пересекает оболочку | Стержень незаметно исчезал | Изменение отклоняется; GUI показывает причину и восстанавливает инспектор |
| Закрытие контроля пересечений крестиком | Изменение применялось как согласованное | Закрытие трактуется как отмена, включая значения инспектора |
| Клик за оболочкой | Выбирался соседний подканал по радиусу метки | Проверка попадания внутрь шестигранника |
| Много подканалов | Поиск соседей сравнением каждой пары | Индексы общих рёбер/углов вместо квадратичного перебора |

## Независимые проверки

Для неповреждённых пучков S=40,65,80,100 мм проверяются:

- сумма площадей полигонов = sqrt(3)/2 × S²;
- сумма площадей жидкости = площадь шестигранника − сумма πD²/4;
- сумма смоченных периметров = 2sqrt(3) × S + сумма πD;
- соседи симметричны, без дублей/ссылок на себя;
- отдельный случай НК другого диаметра у оболочки;
- 60 воспроизводимых действий выбора, удаления, восстановления и изменения диаметра (seed 20261127).

Допуск сумм учитывает существующее округление гидравлики каждого подканала до 0.001 мм²/мм.
Для исходных S=65, P=12.75, D=9.1 мм исправленная площадь жидкости: 2423.220 мм²
вместо 2618.328 мм². Суммарный смоченный периметр: 768.348 мм; общий Dh: 12.615 мм.
После обновления следует пересчитать y+ и расход, если они рассчитывались по всей
сборке или по угловым подканалам. Существующая CFD-сетка здесь не исправляется.

Замер в среде разработки: S=300, P=5, D=2 мм — 3571 стержень, 7140 подканалов,
около 1.03 с на построение модели. Отрисовка Matplotlib в замер не включена;
это не гарантия времени на другом компьютере.

## Пределы проверки

Это регрессионный аудит, не доказательство отсутствия всех уязвимостей. Контроль
ресурсов относится к генерации решётки, не ко всему процессу и любым входным файлам.
Автоматическое исправление пересечений двух НК/ИК не выполняется. Произвольные
удаления стержней и крупные трубы могут давать незаполненные области/сложную
топологию: проверка полноты жидкости для всех подобных сочетаний здесь не заявляется.
Случаи без достаточного числа стержней не создают пригодную полную сетку автоматически.
Периферийные/угловые подканалы по-прежнему имеют отдельные ограничения сеточного
построителя; этот аудит не добавляет их CFD-экспорт. Реальная работа под Windows
и большие интерактивные сцены требуют пользовательской проверки.

# meshBuilder

Генератор структурированных сеток для CFD-расчётов пучков стержней (ТВС) с треугольной решёткой и интеграцией со STAR-CCM+.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

- **Графический интерфейс (GUI):**
  ```bash
  python mesh_gui.py
  ```
- **Конструктор подканалов и экспорт в STAR-CCM+:**
  ```bash
  python bundle_subchannel_builder.py
  ```
- **Консольный режим (CLI):**
  ```bash
  python mesh_core.py --help
  ```

## Экспорт и подготовка расчёта в STAR-CCM+

1. В конструкторе выберите подканалы, постройте сетку и, для режима независимого пристеночного слоя, заполните ядро.
2. Нажмите «Экспорт STAR-CCM+» и сохраните сетку `.xyz` и сгенерированный макрос `.java` в отдельную папку.
3. Файл макроса должен называться `setup_starccm_subchannels.java`: имя должно совпадать с именем его Java-класса. Если при сохранении вы выбрали другое имя, переименуйте файл. Имя файла сетки должно оставаться таким, какое указано в макросе.
4. Создайте новую пустую симуляцию STAR-CCM+ и сохраните её в ту же папку. Выполните макрос через команду Play Macro. Макрос использует относительный путь к сетке и изменяет активную симуляцию: импортирует сетку и создаёт объекты согласно выбранным настройкам экспорта.
5. Сравните число ячеек с meshBuilder и выполните диагностику импортированной сетки. Проверьте объёмы ячеек, качество сетки и состав границ.

### Граничные условия задаёт пользователь

**После импорта исходный тип всех внешних границ — Wall**, в том числе у поверхностей с именами `in_1`, `out_1` и `sym/per`. Это намеренное начальное состояние: пользователь самостоятельно выбирает типы и значения граничных условий под свою задачу. Имена поверхностей помогают их найти, но не назначают физическое условие.

Перед запуском расчёта откройте `Regions → нужный регион → Boundaries` и настройте каждую границу:

- Для задачи со сквозным течением назначьте входу и выходу подходящие типы, например Velocity Inlet и Pressure Outlet, и задайте требуемые значения.
- Для поверхностей стержней и боковых поверхностей выберите условия согласно физической модели. Боковые поверхности могут оставаться стенками, если так задумана задача. Название `sym/per` само по себе не создаёт симметрию или периодическую связь.
- Проверьте параметры физики, свойства среды, начальные условия и настройки решателя. Созданные макросом параметры, отчёты и мониторы не заменяют эту проверку.

Пока вход и выход остаются Wall, область закрыта и сквозного течения через них нет. Успешное выполнение макроса означает подготовку объектов симуляции, а не подтверждение корректности или сходимости CFD-расчёта.

### Проверенный пример импорта

Пользователь вручную проверил сгенерированный макрос в **STAR-CCM+ 2602** на одном подканале: созданы регион, физика, отчёты, мониторы, плоскости и линии. Число гексаэдральных ячеек после импорта совпало с meshBuilder — **431 880**. По предоставленному отчёту диагностики все объёмы положительные, Face Validity равна 1 у всех ячеек, минимальный Volume Change — около 0,9025.

Эта проверка относится к одному примеру. Расчёт течения не выполнялся, его сходимость не оценивалась; совместимость всех вариантов настроек и других версий STAR-CCM+ не подтверждена.

## Основные модули

- `mesh_gui.py` — графический интерфейс (PySide6) и визуализация.
- `mesh_core.py` — расчёт сетки, законы распределения, независимый пристеночный слой и CLI.
- `mesh_quality.py` — расчёт и интерпретация метрик качества сетки.
- `mesh_project.py` — сохранение и загрузка проектов (`.json`).
- `bundle_geometry.py`, `bundle_subchannel_builder.py`, `mesh_subchannel.py` — подканальная геометрия и построение.
- `bundle_project.py` — полный проект конструктора, проверка формата и атомарная запись JSON.
- `fluid_properties.py`, `yplus_calculator.py` — свойства теплоносителя и расчёт `y+`.
- `starccm_macro_generator.py` — генератор Java-кода для STAR-CCM+; `setup_starccm_subchannels.java` — имя создаваемого файла, а не входной шаблон.

## Свойства воды

Для жидкой воды используются IF97 (регион 1), вязкость IAPWS 2008 и теплопроводность IAPWS 2011 с явным выбором критического усиления через `iapws==1.5.5`.
После обновления установите зависимости из `requirements.txt`.
Диапазон, единицы, контрольные значения и ограничения описаны в [docs/water_transport.md](docs/water_transport.md).
